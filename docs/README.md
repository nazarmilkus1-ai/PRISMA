# Документация PRISMA

Список файлов в docs/:
- AGENT.md — инструкции для автономного агента разработчика
- ARCHITECTURE.md — архитектура проекта: компоненты, границы, потоки данных, безопасность
- CONFIGURATION.md — настройка окружения для бота, сайта, панели и плагина
- DEVELOPMENT.md — рабочий процесс разработки: порядок реализации, реестр модулей, правила БД
- FAQ.md — ответы на частые вопросы о стабильности, версиях, Bedrock, Redis, лицензии
- FEATURE_MODULE_TEMPLATE.md — шаблон для создания новых функциональных модулей
- GETTING_STARTED.md — пошаговое руководство по локальному запуску всей экосистемы
- GUARDIAN.md — описание системы стража (автоматическая модерация и защита)
- MINECRAFT_AUTH.md — авторизация в Minecraft: связь Telegram, сайта и игры
- MODULES.md — описание модульной системы и реестра модулей
- OPERATIONS.md — эксплуатация: деплой, здоровье, бот, плагин, релизы, откаты, инциденты
- PRISMA_2.1.0_ANNOUNCEMENT_RU.md — анонс версии 2.1.0 на русском
- PRISMA_2.1.0_AUDIT_RU.md — аудит версии 2.1.0 на русском
- RELEASE_STATUS.md — текущий статус релиза и гейты верификации
- VERCEL_SERVICES.md — настройка и особенности сервисов Vercel для сайта и панели

Все файлы актуальны для версии 2.1.0 (интеграционный кандидат).
