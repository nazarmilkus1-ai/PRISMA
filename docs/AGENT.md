# PRISMA-агент (автономный разработчик)

Живёт **только** в топике админ-группы (chat `-1004365081749`, thread `1469`), работает 24/7 сам.

- Цикл каждые ~10 мин: читает сообщения людей (админы = приоритет, остальные = предложения), память, цель → работает инструментами → итог в журнал.
- Своя цель, свой план, % готовности и % «работает» (по CI). Менять ожидания и идеи можно.
- Код: только ветки `agent/*`, атомарные коммиты через Git Data API, PR открывается сам. Нельзя `.github/`, env, секреты.
- Каждый час отчёт в топик + кнопка **✅ Слить** (только владелец или `AGENT_MERGE_ADMIN_IDS`; CI должен быть зелёным; миграции БД не сливаются кнопкой; BLOCK ревьюера — только владелец «Слить всё равно»).
- Память: закреплённое ядро + полнотекстовый поиск + ежедневное сжатие старых заметок.
- Второй ИИ (ревьюер, ключ `AI_API_KEY_ADMIN`) читает diff и даёт OK/RISKS/BLOCK.
- Команды админов в топике: `/agent_pause`, `/agent_resume`, `/agent_status`.

Env (Render): `AI_API_KEY_AGENT`, `AI_MODEL_AGENT` (список через запятую), `AI_MODEL_REVIEWER`, `AGENT_ENABLED`, `AGENT_MERGE_ADMIN_IDS`, `AGENT_CHAT_ID`, `AGENT_THREAD_ID`, `AGENT_DM_COPILOT=1` (вернуть старого агента в ЛС).
