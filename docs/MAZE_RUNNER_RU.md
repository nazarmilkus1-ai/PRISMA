# Режим Maze Runner для PRISMA

## Что добавлено

Режим включается отдельным переключателем **«Игровой режим Maze Runner»** в панели PRISMA: `/admin/dashboard/modules`. В forward migration он создаётся выключенным. Это намеренно: сначала нужно импортировать карту и указать центр Глейда.

Плагин хранит настройки в runtime-файле `plugins/PrismaPlugin/maze-runner.yml`; этот файл не хранится в Git и не перезаписывается при каждом запуске.

## Настройка после импорта карты

1. Загрузите карту как отдельный мир сервера и зайдите в неё с правами персонала.
2. Встаньте примерно в центре Глейда и выполните `/maze setglade`.
3. Для поляны 200×200 оставьте настройку по умолчанию или задайте `/maze gladesize 100`. Это полуразмер по X/Z от сохранённого центра.
4. Радиус игровой области по умолчанию — 1500 блоков. При необходимости измените его через `/maze maze-radius 1500`; ограничение нужно, чтобы спавн не уходил далеко за карту.
5. Включите **«Игровой режим Maze Runner»** в панели и выполните `/maze start`.

Команды персонала: `/maze status`, `/maze setglade`, `/maze gladesize <50–250>`, `/maze maze-radius <250–5000>`, `/maze start`, `/maze stop`, `/maze clear`. Для них используется уже существующее разрешение `prisma.command.spawnmanage`.

## Поведение первого этапа

- Ночью в загруженном мире карты плагин может создавать до 8 управляемых пауков с именем **Гривер** рядом с игроками, которые находятся внутри игровой области, но за пределами Глейда.
- Гриверы не спавнятся в безопасной зоне. Их урон по игроку внутри Глейда отменяется, даже если игрок привёл моба туда.
- Убийство управляемого Гривера выдаёт обычный предмет-компас с названием «Компас Гривера» — это соответствует условию карты о компасе для финального прохода.
- Днём управляемые плагином Гриверы удаляются. Если режим выключить через панель или состояние панели перестанет подтверждаться, новые Гриверы не спавнятся, а уже созданные убираются.
- Мобы помечаются через Persistent Data Container. Очистка затрагивает только Гриверов, созданных этим режимом; обычные мобы и сущности карты не удаляются.

## Что пока не включено

В этой итерации **не реализованы** собственный таймер открытия/закрытия ворот, изменение проходов Narrows, восемь уникальных секций, домены с выдачей шерсти и проверка размещения всех цветов на монументе. Для этого нужны тестовый импорт карты и проверка её настоящих координат/встроенных redstone-команд: без этого опасно менять блоки или повторно запускать механизмы, которые уже есть в карте.

Никакие production-миграции, вайп, импорт мира или запуск режима автоматически не выполняются.
